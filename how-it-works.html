Common questions

Still trying to break it?

Can I edit the generated lessons?

Yes. Every lesson is editable in the dashboard or via API. Edits are tracked, and re-running the source material won't overwrite your changes unless you explicitly regenerate.

What if my source content is in Lithuanian and I need English?

Source language is auto-detected. You pick the output language per course. Mixed-language source is fine — common in Baltic teams where the manual is English but the manager's voice notes are in Lithuanian.

How do you handle confidential material?

EU-only processing, encrypted at rest, never used for training. You can delete a course (and all derived content) from the dashboard or via DELETE /v1/courses/:id. We'll send you an audit log to confirm.

Does it work with my existing LMS?

SCORM 1.2 and xAPI exports. Direct integrations with Moodle, TalentLMS, and Docebo. For everything else, the API gives you raw lesson content as Markdown + JSON.
