Introduction

Neuropetitorius is a B2B API that takes sparse business content — manuals, PDFs, recordings — and returns a complete, structured training course. This is the documentation for the v1 API.

Most teams use one of three integrations: drop into the dashboard for end-to-end course building, embed our learner UI on a custom domain, or use the API directly to render lessons inside your own product. Pick the path that matches the kind of product you're shipping.

Install & authenticate

The API base URL is https://api.neuropetitorius.com/v1. All requests require a Bearer token — generate one in the dashboard under Settings → API keys. Keep it server-side; client-side use is rejected.

bash
# Set your key in an env var, never commit it
export NPT_KEY="npt_sk_live_…"

# Smoke test
curl https://api.neuropetitorius.com/v1/me \
  -H "Authorization: Bearer $NPT_KEY"

Or install one of the official SDKs:

terminal
# Node / TypeScript
npm install @neuropetitorius/sdk

# Python
pip install neuropetitorius

# Go
go get github.com/neuropetitorius/go-sdk
★

Test mode is free. Use npt_sk_test_… keys to call any endpoint with no charge or learner-quota impact. Test courses are flagged in the dashboard and deleted after 30 days.

Your first course

The shortest path: POST a folder of source files to /v1/courses, listen for the course.ready webhook, and fetch the lessons.

node
import { Neuropetitorius } from "@neuropetitorius/sdk";
const npt = new Neuropetitorius(process.env.NPT_KEY);

const course = await npt.courses.create({
  sources: [
    { type: "file", path: "./cashier_handbook.pdf" },
    { type: "file", path: "./manager-tips.m4a" },
  ],
  target_audience: "front_of_house_new_hires",
  output_language: "en",
});

// Course is built async — listen for the webhook
console.log(course.id, course.status); // "crs_8h2k…", "building"

Core concepts

Three objects to know:

  • Course — a top-level training program. Has lessons, quizzes, and learners.
  • Source — anything you upload (PDF, audio, etc.). Sources are immutable; reprocess by adding new ones.
  • Learner — a person taking the course. Each has progress, scores, and an event stream.

Create a course

POST /v1/courses

Submit one or more sources and get back a building course. The build is async; subscribe to course.ready or poll the retrieve endpoint.

Body parameters

NameTypeDescription
sourcesarray<Source> req1–50 source objects. Each is either a file upload or a URL.
target_audiencestringFree-text descriptor of who's taking the course. Improves lesson tone and depth.
output_languagestringISO 639-1 code (en, lt, de, …). Default: detected from sources.
generate_quizzesbooleanDefault true. Set false for read-only courses.
metadataobjectUp to 16 key-value pairs. Returned on every course response.

Returns

A Course object with status: "building". Once ready, all lesson content is accessible at /v1/courses/:id/lessons.

200 OK
{
  "id": "crs_8h2k4mZ9",
  "object": "course",
  "status": "building",
  "created": 1746710400,
  "target_audience": "front_of_house_new_hires",
  "output_language": "en",
  "estimate_seconds": 2940,
  "sources": [
    { "id": "src_p4q…", "type": "pdf", "size_bytes": 2456789 },
    { "id": "src_a9k…", "type": "audio", "duration_seconds": 1380 }
  ],
  "metadata": {}
}

Retrieve a course

GET /v1/courses/{course_id}

Returns the course with its full lesson tree once status is ready.

Webhooks

Subscribe to events instead of polling. Configure endpoints under Settings → Webhooks in the dashboard. We sign every request with HMAC-SHA256 in the NPT-Signature header.

EventWhenPayload
course.readyBuild completesFull Course object
course.failedBuild failsCourse + error details
learner.completedLearner finishes courseLearner + final scores
quiz.failedLearner fails a quiz twiceLearner + quiz attempts
!

Verify signatures. Always verify the NPT-Signature header. Unsigned requests should be rejected — anyone could otherwise POST fake events to your endpoint.

Audio sources

Audio is a first-class source type. We auto-transcribe (whisper-class accuracy), detect speaker turns, and chunk by topic before lesson generation.

Supported formats: M4A, MP3, WAV, FLAC, OGG, MP4 (audio track). Files up to 2 GB on Studio, larger on Enterprise.

Errors & rate limits

Standard HTTP codes. Errors return JSON with error.code, error.message, and a request_id for support tickets.

CodeStatusMeaning
400bad_requestMalformed JSON or invalid parameters
401unauthorizedMissing or invalid API key
402quota_exceededPlan limit reached — upgrade or wait for cycle reset
404not_foundResource doesn't exist or was deleted
429rate_limitToo many requests — back off and retry with exponential delay
500server_errorSomething broke on our side. Retry safe.

Rate limits are 60 requests/minute on Studio, custom on Enterprise. Webhook deliveries don't count against your limit.
